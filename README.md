# DIPSY BY DV — ритуал-віджет (MVP-скетч)

Один файл, без білду: `index.html`. Квіз → підбір продукту → hand-tracking ритуал.

## Як запустити

Камера працює **тільки на HTTPS або localhost**. Просто відкрити файл подвійним кліком (`file://`) — не спрацює: заблокується і камера, і завантаження модулів Mediapipe з CDN.

**Найшвидший шлях — Netlify Drop:**

1. Відкрити https://app.netlify.com/drop
2. Перетягнути туди **всю папку** `dipsy-ritual`
3. Отримати HTTPS-лінк, відкрити на телефоні

**Локально (якщо є Python):**

```
cd dipsy-ritual
python -m http.server 8001
```
далі http://localhost:8001

## Що вже працює

- 4 питання → 4 профілі (`Тиша / Відновлення / Пробудження / Затишок`) через просту систему балів
- Mediapipe HandLandmarker, детекція кругових рухів долоні, лічильник кіл
- Fallback без камери — дихальний таймер (якщо відмовили в доступі)
- Overlay: landmarks + коло, яке система бачить зараз; кільце прогресу поточного кола
- Камера вимикається при згортанні вкладки

## Як влаштований підрахунок кіл

Центр долоні = середнє з landmarks 0 / 5 / 17. Масштаб долоні = відстань 0→9 (щоб пороги не залежали від того, наскільки далеко рука від камери). Координати переводяться в ізотропний простір (x × aspect), інакше кола перетворюються на еліпси і кут «пливе».

Далі: ковзне вікно ~1.1 с → центроїд вікна = центр кола → кут поточної точки відносно центроїда → накопичуємо зміну кута → 2π = одне коло.

Захисти:

- радіус менший за 0.22 розміру долоні не рахується (тремтіння, нерухома рука)
- стрибок кута > 0.9 рад/кадр ігнорується (збій трекінгу)
- зміна напрямку зменшує накопичувач → махання туди-сюди не накручує лічильник

## Перевірено на синтетичних траєкторіях

| Сценарій | Очікувано | Результат |
|---|---|---|
| Кола r=0.10, 1 об/с, 5 с | 5 | 4.6 |
| Кола r=0.05, 0.7 об/с, 12 с | 8.4 | 7.96 |
| Кола + дрейф руки вбік | 5 | 4.6 |
| Нерухома рука + шум ±0.02 | 0 | 0 |
| Махання ліво-право | 0 | 0 |
| Мазки вгору-вниз | 0 | 0 |
| Дрібне тремтіння r=0.01 | 0 | 0 |

Систематичний недолік ~0.4 кола — це стартова затримка (треба накопичити вікно). Помиляється **в бік недорахунку**, не перерахунку — це правильний бік для такого віджета.

## Що свідомо НЕ зроблено

- **Назви продуктів вигадані не були.** У `PRODUCTS` — типи продуктів з каталогу (гель, лосьйон, скраб, крем для рук, свічка) і посилання на реальні категорії сайту. Реальні SKU, ціни, фото — підставити з каталогу.
- Немає Lottie-анімацій, голосу, аналітики.
- Кольори: `--wine:#622735` взято з `meta-theme-color` сайту. Решта палітри — моя, підганяти під бренд-гайд.

## Вбудовування в сайт (Weblium)

Сайт зроблено на **Weblium** (видно з `meta-generator`). Вбудовувати через HTML-блок:

```html
<iframe src="https://ВАШ-САЙТ.netlify.app/"
        allow="camera; fullscreen"
        style="width:100%;max-width:520px;height:760px;border:0;display:block;margin:0 auto"
        title="Ритуал DIPSY"></iframe>
```

`allow="camera"` обовʼязковий — без нього камера в iframe не запуститься навіть на HTTPS.
